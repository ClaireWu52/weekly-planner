# My Planner 我的计划本

一个网页版的个人计划本：课表、任务、健康、目标、学习、成长记录和生活小工具都在一起。

## 怎么打开

**在线使用：** https://clairewu52.github.io/weekly-planner/

**在自己电脑上用：** 点这个页面上方绿色的 **Code → Download ZIP**，解压后双击 `index.html`，用浏览器打开就能用。

所有记录都自动保存在当前浏览器里。换电脑或换浏览器之前，点右上角 **⋯ → 导出全部数据**（衣橱照片也会一起导出），到新的地方再 **导入备份**。

**每日新闻需要一次设置：** 仓库的 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。之后网站每天自动更新两次新闻。

## 功能

**今天**：今天的课表安排、三件重点、每日任务、快到期的待办、喝水和心情快记、习惯、本月重点、新闻头条、心愿进度和专注计时器。另有「今日新闻」分页，按科技、AI、商业、财经分类，来源包括 BBC、纽约时报、CNBC、MIT Technology Review 等。

**任务**
- 习惯：好习惯点 +，坏习惯点 −，看最近 7 天的趋势
- 每日任务：按星期重复，记录连续天数
- 待办：截止日期、优先级、子任务清单，可以设为“今天的重点”

**课表**：课程、自习、工作、社团、运动、生活等类别，点图例可以隐藏某一类；拖动新建、改时间、换天；可以写备注、快速选时长、复制；每周固定的安排可以设起止日期（比如只排到期末）；手机上可以按天看；自选内容打印或存成 PDF。

**健康**
- 运动记录：先建好训练组（比如“下肢力量：深蹲 4×8、硬拉 3×6…”），记录时选一个组就自动填好，再按实际改动作、组数、次数和重量
- 每周总结：次数、分钟、按类型统计、做得最多的动作、近 4 周对比
- 运动计划：给本周或下周每天选训练组和时间，一键加进课表
- 喝水、睡眠、心情、健康打卡、一分钟呼吸放松

**目标**：年度关键词和愿景、带衡量标准的年度目标、全年时间线、每月拆解；心愿清单绑定解锁条件，可以自动统计进度。

**成长**：阅读清单（页数进度、评分、笔记、年度目标）、课程和技能、资源收藏；成长记录和一整年的活跃热力图。

**生活**
- 今天吃什么：把常吃的放进转盘，每个选项还可以存常去的店
- 电子衣橱：拍照上传衣服，按类别和季节整理，存搭配，随机搭一套，记录穿了几次
- 旅游攻略：每个目的地一页，打卡景点、住宿、美食、出片攻略和行李清单，一键搜小红书、Google 或地图

**其他**：撤销、导出和导入备份、中英文切换、深色模式，手机上也能用。
