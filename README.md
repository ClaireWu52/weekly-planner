# My Planner 我的计划本

一个网页版的个人计划本：课表、任务、健康、目标、学习、成长记录和生活小工具都在一起。

## 怎么打开

**在线使用：** https://clairewu52.github.io/weekly-planner/

**在自己电脑上用：** 点这个页面上方绿色的 **Code → Download ZIP**，解压后双击 `index.html`，用浏览器打开就能用。

**装到手机桌面：** 点右上角 **⋯ → 装到手机桌面**，按提示添加。装好后像一个 App，没网也能打开。iPhone 上建议一定要加到主屏幕，否则 Safari 可能会清掉很久没打开的网站数据。

所有记录都自动保存在当前浏览器里。想让手机和电脑保持一致，点 **⋯ → 同步设置**，用 GitHub 令牌和自己设的同步密码开启（数据先加密再上传；两台设备各自改了东西，比如手机上加了一个待办、电脑上又加了一个，同步后两边的修改都会保留；在新设备上开启，或者关掉后重新开启时，以云端为准，这台设备原来的内容会先存一份，30 天内可以在同步设置里下载成备份文件；只有同一项的同一处两边都改了，才以最后改的为准；衣橱照片也会加密同步，单独放在另一个私密 Gist 里，只上传新加或换过的照片，不想同步照片可以在同步设置里关掉）。从另一台设备同步过来修改时，会显示一行拿到了什么（比如「待办 +3、运动记录 +1」）。也可以手动 **⋯ → 导出全部数据**（衣橱照片也会一起导出），到新的地方再 **导入备份**。没开同步的话，超过 30 天没导出备份，今天页顶部会提醒一下。

**每日新闻需要一次设置：** 仓库的 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。之后网站每天自动更新两次新闻。

## 功能

**今天**：顶部有一个「随手记」输入框，写什么都行：「周五交作业」会变成待办，「喝了2杯水」「跑步30分钟」「心情4」「睡 23:30-7:10」「花了25午饭」会直接记到对应的地方。今天的课表安排、三件重点、每日任务、快到期的待办、喝水和心情快记、习惯、本月重点、新闻头条、心愿进度和专注计时器。日期下面会显示连续活跃了几天（今天还没活跃时会提醒你做一件事接上）；日期旁边会显示现在是学期的第几周、离期末还有几天；快到的生日和纪念日会提前几天出现；填好所在城市后会显示今天的天气，并从衣橱里按天气搭一套（天凉会加外套，下雨提醒带伞），也会提醒很久没穿的衣服。晚上 7 点以后会出现「今晚收尾」：总结今天做了什么，把没做完的重点一键挪到明天，写下明天最重要的一件事和一句话的今天（会显示在每周回顾里）。专注计时可以选一件待办，专注的时间会记在这个待办上。第一次打开时有三步的小引导。还没有内容的卡片会自动收起，在 **⋯ → 自定义页面** 里可以关掉不想看的卡片、用 ↑ ↓ 调整顺序，或者设成「收起」只显示一行标题（每张卡片标题右边的 ⌃ 也能直接收起）。周末和周一、周二，如果还没写每周回顾，顶部会提醒一下。另有「今日新闻」分页，按科技、AI、商业、财经分类，来源包括 BBC、纽约时报、CNBC、MIT Technology Review 等。

**任务**
- 习惯：好习惯点 +，坏习惯点 −，看最近 7 天的趋势
- 每日任务：按星期重复，也可以每两周一次或每月几号（比如每月 1 日交房租，31 日在小月会自动挪到月底），记录连续天数；可以设成自动打卡（记了运动、喝水达标、记了睡眠、专注过一次、记了心情）
- 待办：截止日期、优先级、子任务清单、预计时长，可以设为“今天的重点”；可以「排进课表」：选好日期和开始时间，课表上就会按预计时长留出这段时间（虚线边），做完后课表上也会划掉，在课表上点它会回到这个待办；快速添加时在开头或结尾写日期（「周五 交作业」「明天考试」「交报告 11月20日」「essay due fri」）会自动设成截止日期

**课表**：同一门课在不同天的安排会一起修改；课程、自习、工作、社团、运动、生活等类别，点图例可以隐藏某一类；拖动新建、改时间、换天；可以写备注、快速选时长、复制；每周固定的安排可以设起止日期（比如只排到期末）；有待办在哪天截止，那天的标题旁会显示「截止 N」，点一下打开那个待办；手机上可以按天看，左右滑动换到前一天或后一天；自选内容打印或存成 PDF。学校选课系统、Google 日历或 Outlook 导出的日历文件（.ics）可以在 **⋯ → 从日历导入课表** 里直接导入：每周的课会变成固定安排（带开始和结束日期，放假那几天自动跳过），单次的安排放进对应那一周，全天事件（比如假期）不导入；导入前会先列出要加的内容，导入后可以撤销。

**健康**：分成三个分页，顶部四个数字（本周运动、喝水、睡眠、心情）点一下就跳到对应的地方。
- 运动
  - 运动记录：先建好训练组（比如“下肢力量：深蹲 4×8、硬拉 3×6…”），记录时选一个组就自动填好，再按实际改动作、组数、次数和重量
  - 本周总结：每周目标和进度、次数、分钟、按类型统计、做得最多的动作、近 4 周对比
  - 运动计划：给本周或下周每天选训练组和时间，一键加进课表
- 作息：睡眠、喝水；健康类的每日任务也会显示在这里，和任务页是同一份
- 放松：心情、一分钟呼吸放松

**成长**：长期的事都在这里。学期：填上开学和期末日期，显示第几周和离期末几天；每门课可以按课程大纲设成绩构成（比如作业 30%、期中 25%、期末 35%，同一类按分数加起来算），也可以给每一项单独填占比；字母成绩可以用常见的美国标准、简单的 90/80/70/60，或者每门课自己设分界线（比如 94 才算 A）；自动算出当前成绩、字母成绩和学期 GPA，设了目标成绩还会告诉你剩下的要考多少；带日期、还没出分的作业和考试会自动变成待办（截止就是那天，课表上也会显示「截止」），打勾后学期页会提醒你填分数，填了分数待办也会自动勾上；接下来的作业和考试按日期列出来；可以从课表一键加入所有「课程」类安排。年度目标（年度关键词和愿景、带衡量标准的年度目标、全年时间线、每月拆解，拆出来的小事点「加到待办」就会进待办，截止到月底，在任一边打勾另一边也会勾上）；心愿清单绑定解锁条件，可以自动统计进度；每周回顾（自动汇总这一周的任务、课表时间、运动、睡眠、心情和专注，写下收获和困难，下周三件重点一键加进待办），旁边还有月度总结和年度总结，以及根据最近 60 天的记录自动发现的规律（比如「睡够 7 小时的日子，心情平均高 0.8 分」「周三是你最能专注的一天」）；阅读清单（页数进度、评分、笔记、年度目标）、课程和技能（在今天页的专注计时里选一门课，专注的时间会记到这门课上）、资源收藏；成长记录和一整年的活跃热力图。

**生活**
- 今天吃什么：把常吃的放进转盘，每个选项还可以存常去的店；最近吃过的会少转到一些
- 记账：日常的花费按类别记，设月预算后显示还剩多少、每天还能花多少，和上个月同期比；备注里写「午饭」「地铁」「课本」会自动分好类；房租、订阅这类每月固定支出，到了那天会自动记一笔；可以导出成 Excel 能打开的表格（.csv）
- 纪念日：家人朋友的生日、纪念日，显示还有几天、几岁或几周年，可以一键加个「准备礼物」的待办，也可以一起导出到手机日历（每年重复）
- 电子衣橱：拍照上传衣服，按类别和季节整理，存搭配，随机搭一套，记录穿了几次
- 旅游攻略：每个目的地一页
  - 每日行程：按天安排，可以直接选收藏的景点和美食，随时改时间或挪到别的天；每天显示天气预报，一键在 Google 地图打开当天的路线
  - 「今天」页：出发前一周提醒（交通预订和还没带的行李），旅行期间显示当天的行程、航班和入住
  - 交通预订：航班、火车、酒店的时间、确认号（一键复制）和地址，到机场一打开就能找到；填了价格会自动记进花费
  - 花费：设预算，用当地货币或自己的货币记账，自动换算汇率；显示每天还能花多少；和朋友一起去会算出谁该给谁多少钱
  - 行李清单：自动按证件、衣物、电子产品、洗漱等分组；按海边、城市、寒冷、徒步等类型一键添加，或者从以前的行程复制；回程时一键全部改回没带
  - 分享：把整个行程生成一段文字，复制发给一起去的朋友（可以选择带不带确认号）
  - 复制行程：再去一次或者拿做好的行程当模板；出发和回来的日期一起改，每日行程会跟着挪
  - 还有景点、住宿、美食、出片攻略，一键搜小红书、Google 或地图；在每日行程里打勾，景点也会标成去过了
  - 景点、美食、行李和没定时间的行程都可以拖动排序（电脑上也可以用方向键）

**其他**：右上角的放大镜（或按 ⌘K / Ctrl+K、/）可以搜索所有内容：待办、课程、作业、书、收藏、旅行景点、衣服、纪念日等，回车直接打开；在 Android 或电脑上装到桌面以后，别的 App 里点「分享」可以把链接或文字存成待办、学习收藏或旅行景点（iPhone 暂不支持）；右上角一键切换中英文；⋯ 菜单里可以隐藏不用的页面，可以把课表、截止日期和旅行的航班、火车、酒店导出到手机日历来提醒；撤销、导出和导入备份、深色模式，手机上也能用。

## 测试

旅行页的计算（汇率换算、谁给谁多少钱、每天还能花多少、行李分组、挪日期、拖动排序）、快速添加里的日期识别、衣橱照片同步时该上传还是下载、两台设备的修改怎么合并、每日任务的重复规则和连续天数、日历文件的读取、课表每周显示哪些安排（起止日期、本周跳过）和重叠时的排列、学期周数和成绩 / GPA、随手记的识别、自动发现的规律、纪念日的日期计算有自动测试，改代码后跑一下就知道有没有改坏：

- 浏览器：打开网站地址后面加 `/tests/`，或者在本地打开 `tests/index.html`
- 命令行：`node tests/run.js`（不用装任何东西，有失败时返回非零）

另外还有模拟点按的测试：在一个隐藏的小窗口里打开整个网站，像人一样输入、点按钮、填表（快速添加待办、排进课表和撤销、随手记、晚上收尾、学期和 GPA、作业变待办、记账和固定支出、纪念日、今天页卡片收起和排序、搜索，以及每个页面中英文都能打开）。这些测试只用内存里的临时数据，不会读也不会改你保存的内容。

- 浏览器：网站地址后面加 `/tests/ui.html`（要用网址打开，直接双击文件不行）
- 命令行：`node tests/ui-run.js`（需要电脑上有 Chrome）
- 每次发布网站前 GitHub 会先自动跑这两组测试，有失败就不发布，网站保持上一个版本
