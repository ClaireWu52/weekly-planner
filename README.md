# Weekly Planner 每周课表

一个可以编辑、可以打印的每周课表网页。

## 怎么打开

**在线使用：** https://clairewu52.github.io/weekly-planner/

**在自己电脑上用：** 点这个页面上方绿色的 **Code → Download ZIP**，解压后双击 `index.html`，用浏览器打开就能用。

修改会自动保存在当前浏览器里。换电脑或换浏览器之前，点右上角 **⋯ → 导出备份**，到新的地方再 **导入备份**。

## 功能

- 每周固定的课程和工作，加上只在某一周的临时安排
- 在空白处拖动新建安排；拖动方块改时间或换到别的天；拖方块底边改结束时间
- 固定安排可以“只改本周”或“本周跳过”，不影响其他周
- 每周的待办和备注
- 自动统计本周课程、工作、社团各花了多少小时
- 打印：自选打印哪几天、哪些类型、时间段、纸张和方向，预览和打出来的一样，一页打完，也可以存成 PDF
- 撤销、导出和导入备份、中英文切换、深色模式，手机上也能用
