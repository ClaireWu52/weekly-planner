# My Planner 我的计划本

一个网页版的个人计划本：课表、任务、健康、目标、学习和成长记录都在一起。

## 怎么打开

**在线使用：** https://clairewu52.github.io/weekly-planner/

**在自己电脑上用：** 点这个页面上方绿色的 **Code → Download ZIP**，解压后双击 `index.html`，用浏览器打开就能用。

所有记录都自动保存在当前浏览器里。换电脑或换浏览器之前，点右上角 **⋯ → 导出全部数据**，到新的地方再 **导入备份**。

## 功能

**今天**：一页看完今天的课表安排、三件重点、每日任务、快到期的待办、喝水和心情快记、习惯、心愿进度，还有专注计时器。

**任务**
- 习惯：做到好习惯点 +，犯了坏习惯点 −，能看到最近 7 天的趋势
- 每日任务：按星期重复，每天自动重置，记录连续天数
- 待办：截止日期、优先级、子任务清单，可以设为“今天的重点”，逾期会标红

**课表**：每周固定安排和临时安排，拖动新建、改时间、换天；固定安排可以只改本周或本周跳过；自选内容打印，也能存成 PDF。

**健康**
- 运动记录：种类、时长、强度、感受，每周目标和近 30 天图表
- 喝水：一点就记一杯，可以改每天的目标
- 睡眠：填入睡和起床时间自动算时长，近 14 天图表
- 心情：五种心情加一句话，近 5 周心情日历
- 健康打卡和一分钟呼吸放松

**目标**
- 年度目标：今年的关键词和愿景，每个目标设几条能衡量的标准，全年时间线看进度
- 每月拆解：把年度目标拆成每个月的小事，可以一键加到待办
- 心愿清单：每个心愿绑一个解锁条件，进度可以自己调，也可以自动统计完成的待办、打卡、运动、专注、读完的书或成长记录，达成后兑现

**成长**
- 学习清单：在读、想读、读完的书（页数进度、评分、笔记、年度阅读目标），在学的课程和技能，按主题收藏的学习资源
- 成长记录：记下值得记住的事，按分类和标签整理；一整年的活跃热力图会把完成的待办、打卡、运动、专注、读书和记录都算进去，还有连续活跃天数

**其他**：撤销、导出和导入备份、中英文切换、深色模式，手机上也能用。
